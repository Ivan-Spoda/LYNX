A lightweight DAW, fully open source.

LYNX is a lightweight, fully open-source DAW with the FL Studio workflow you already know — Channel Rack, Piano Roll, Playlist and Mixer — built in modern C++ to run smoothly on any PC. It even opens your .flp projects.

// why lynx

Everything you need. Nothing slowing you down.

A lock-free engine that spreads channels and mixer tracks across your CPU cores, skips idle channels and streams long audio from disk.

0×

faster than real time — our 46 s demo renders in 0.93 s

0+

FL Studio native plugins recreated or converted on import

0M

automated checks run on every build

0 $

free forever, open source under AGPL-3.0

Lightweight

Multithreaded audio graph, disk streaming and a GPU-friendly UI. Runs on old laptops too.

The FL workflow

Step sequencer, patterns, Piano Roll, Playlist and a Mixer with inserts, sends and sidechain. Same shortcuts.

Opens .flp

Imports FL Studio projects: channels, samples, patterns, arrangement, automation, mixer and native plugins.

Clean-room

Behaviour studied and documented, then written from scratch. Not a single line of Image-Line code.

01 · playlist

Arrange your whole song

Patterns, audio and automation clips side by side, with markers, arrangements, time selection and a knife tool.

  • Multiple arrangements per project
  • Automation clips with curves for any knob
  • Song/Pattern mode in one click
02 · piano roll

Write melodies fast

Snap, chords and scales, slide and porta notes, velocity and pitch lanes, strum, arpeggiate and randomize tools.

  • Ghost notes from other channels
  • MIDI import and export
  • Type notes with your PC keyboard
03 · mixer

Mix like a pro

Up to 127 inserts, 10 effect slots per track, sends, sidechain, delay compensation and smart disable.

  • Parametric EQ, compressor, limiter, reverbs, delays…
  • VST3 and CLAP plugins, optionally sandboxed
  • Export WAV, stems and MIDI

// built-in plugins

Native plugins, rebuilt from scratch.

Each engine is written natively in LYNX, inspired by an FL Studio plugin and checked against the original running unmodified. Exact means bit-identical output.
