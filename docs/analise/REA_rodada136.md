## 1. Decapitator → Ember Saturator, Classic voicing (`src/core/EmberClassic.*`)

### 1.1 Control laws [EXEC]
- Drive: small-signal gain −2.0 dB + 3.3 dB per knob unit (0 … 10); the saturation ceiling does not move with drive,
  i.e. y = K·f(G·x). Auto gain changes nothing in the audio path when Drive is set through the parameter API: it is
  the editor turning Output down — her states hold that Output.
- Low cut: a 2nd-order high-pass at the knob's frequency, Q 0.847 (max error 0.1–0.3 dB over 20 Hz … 1 kHz); Thump =
  the same filter at Q 1.51 (0.15–0.4 dB).
- Tone: a 2nd-order tilt: pole pair fixed (494.6 Hz, Q 0.352), zero pair at 494.6 · 10^(−0.9946 t/20) Hz, highs at
  +0.3935 t dB (t > 0) / +1.5885 t dB (t < 0) — span exactly 2t dB; within 0.25 dB / 2° over ±12 dB.
- High cut: a 31-tap linear-phase FIR (zero phase relative to the path, identified by least-squares deconvolution of
  impulse responses, residual < −55 dB), gentle and steep; no textbook design matched (windowed Butterworth / bilinear
  targets ≤ −18 dB), so LYNX keeps the measured taps on a 69-point grid of the knob (interpolation within 0.05 dB
  gentle / 0.1 dB steep of the measured mid-points).
- Mix: linear; the dry tap is the raw input delayed by the plug-in's latency (62 samples) with no filtering. Output
  scales the wet path, and the dry part follows it partly the wetter the mix (no simple law fits): a measured
  21 × 13 grid (mix 0 … 100 % × output 0 … −24 dB).
- The wet path: 63 samples (the dry + 1) and a fixed passband colour (+1.5 dB at 18 kHz, steep above 20.5 kHz):
  a 16-tap FIR per style after the curve (0.14 dB / 2.7° for A).

### 1.2 The curve [EXEC + model]
Scatter of the inverted output against the input shows memory: lows saturate earlier than mids (100 Hz at −50 dBFS,
drive 10: −47 dB residual vs −66 at 1 kHz), and the duty cycle shifts with level (a level-dependent bias). LYNX's
engine: pre-emphasis shelves, the drive gain, an asymmetric soft clipper s(v) = v/(1+|v/c|^p)^(1/p) (own c, p per
side) whose bias follows the low-passed curve output (coupling-capacitor "blocking"), de-emphasis, a DC blocker, the
style FIR, the High cut FIR, the aligned dry mix — ×4 oversampled with a 59 + 19-tap half-band pair so that the whole
path keeps Ember's fixed latency (55 samples). Constants fitted (Nelder–Mead in the lab, stairs at six frequencies,
bursts, her takes at drives 1 … 6).

## 2. PanMan → Auto-pan, Rhythm voicing (`src/core/RhythmPan.*`)

### 2.1 Structure [EXEC]
- A balance (each channel keeps its side: a left-only input never reaches the right), equal-power gains
  L·cos θ, R·sin θ; θ = 45° + offset/2 + width/4 · value, clipped to 0 … 90° (width 0 … 210°).
- The pattern: N step values per period. Smoothing is the fraction of each step spent gliding linearly from the
  previous value (a 2-step pattern with full smoothing is a triangle, with 4 % a square with 10 ms ramps); at least
  ~55 samples. Her patterns: left / right (±1) and an 8-step ramp (−1, −½, 0, ½, 1, ½, 0, −½).
- Period: free in Hz (exactly the Rate: 3.560 / 0.570 Hz), or locked to the song position in beats at the host tempo
  (1, 4, 8 beats); one state follows its own stored tempo (121.9 BPM = 2.03 Hz). Free patterns start from a reset;
  synced ones are locked to ppq 0 (a 37 000-sample song offset shifts them exactly).
- Analog mode: a first-order low-frequency section (fitted on the analog / digital ratio) and, per input channel,
  an asymmetric soft saturation (−0.2 dB at −12 dBFS, −2.7 dB at 0 dBFS; H2 −25…−30 dBc); four of her states have a
  "hot" stage instead: a fast linked RMS compressor (3.2 ms detector, 4.9 ms attack, 5.3 dB knee, 2.2:1 above
  −11.2 dB) with almost no harmonics.
- Latency 45 samples (compensated by the host); the oversampler's passband colour as a causal 16-tap FIR.

Each of her 50 states was assigned to one of 12 measured behaviours (pan trajectory within 1°) and fitted
(`panfit.py`: period, start phase, values, smoothing; RMS error 0.08–0.8°).

## 3. Little AlterBoy → LYNX Tune (new substitute; before: none — the slot was left out, i.e. dry)

[EXEC] The trial resynthesises even at neutral settings (latency 2419 samples, −2.7 dB, null vs the input −10.8 dB),
so a waveform null is not a target; spectra, level and the pitch behaviour are.
- Quantize: snaps to the nearest semitone (~85–90 % of the way on steady detuned tones) within ~10–15 ms; Transpose:
  pitch shift only. → LYNX Tune chromatic at the fastest retune; Transpose = every note bypassed.
- Formant: the same direction as LYNX Tune's shift (up = brighter); the trial's formant-up also lowers the lows
  (−6 dB at +6 st), LYNX Tune's does not [model gap]. LYNX Tune gets an appended "Wide formant" (±12 st) for her
  −12 st state.
- Drive (200 Hz stairs, drive 0 … 10): y = K·(s(G·x + b) − s(b)), G = −2.65 + 3.65·drive dB, K = +0.75 − 1.99·drive
  dB (an output compensation: the ceiling drops as the drive rises), c 1.27, p 2.05, b 0.34 — levels within 0.5 dB,
  H2 / H3 within a few dB. LYNX Tune gets an appended "Drive stage" + "Drive" (+ "Output").

## 4. EchoBoy → Echoform, Tape voicing (`echoform::tapeVoicing`)

[EXEC] Impulse trains (feedback set to 0) show NO delay modulation: every first-pass delay is constant and integral
across 20 s and repeat runs, so the system is linear and time-invariant except a soft saturation on its input
(her ping-pong style: the exact low-level impulse response alone nulls her take at −16 dB with +1.1 dB of level;
with the input saturation −26 dB). Structures (the trial's 32-sample latency removed):
- ping-pong (her edited style, 9 + 6 + 3 + 2 states): both inputs summed; left echo one beat + 38, right two beats + 43,
  each recirculating every two beats (×0.356 / 0.130 / 0.062 by state); eight diffusion taps around each first tap
  (−0.153 × the tap at −595 / −493 / −366 / −300, +0.148 at +300 … +595 on the left; −641 / −519 / −465 / −331 / +331 …
  +641 on the right);
- studio tape, single (and its 1/8-note, saturated variant): each side its own; left T − 184 and 2T + 296, right
  T + 200 and 2T − 280 (alternating), the second tap at √(G / G₀) × its measured ratio, a 2T loop;
- each pass's colour: the kernel deconvolved from the response, fitted as a 3rd-order IIR (−21 dB ping-pong, −57 dB
  studio tape; a long negative tail = a low cut); equal-power mix (her 50 / 53 % states).
